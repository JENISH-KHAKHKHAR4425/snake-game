# 🐍 Snake Game

A classic Snake game built with Python and Pygame — now with pause, sound effects, high scores, and mobile-friendly touch controls! 🎮

## ✨ Features

- 🎮 Start / Restart screen with clickable buttons
- ⏸️ Pause anytime with the Space bar or on-screen button
- 🏆 High score saved automatically between runs
- 🍎 Polished food graphics with a subtle pulse animation
- 📱 On-screen touch controls for mobile play
- 🎵 Built-in sound effects (no extra audio files needed)
- ✨ Smooth, interpolated snake movement

## 🛠️ Requirements

- 🐍 Python 3.8+
- 📦 `pygame`
- 📦 `numpy` (for sound effects)

## ⚙️ Installation

```bash
pip install pygame numpy
```

## ▶️ How to Run

```bash
python snake_game.py
```

## 📱 Running on Android

1. Install **Pydroid 3** from the Google Play Store
2. Install `pygame` and `numpy` via Pydroid's Pip menu
3. Open `snake_game.py` in Pydroid 3
4. Tap ▶️ Run

## 🎹 Controls

| Action | Key / Touch |
|---|---|
| Move | Arrow keys / WASD / on-screen arrows |
| Pause | Space bar / on-screen Pause button |
| Restart | R (on Game Over screen) |
| Quit | Q (on Game Over screen) |
